Tweet Format Rotation
4 Structural Templates — Picked by deal_id % 4

Same deal ID always gets the same format (deterministic), so A/B data is consistent across re-posts.

bullet_caps id % 4 == 0
HOOK LINE IN CAPS ✅ Feature one ✅ Feature two ✅ Feature three CTA + affiliate link #QuadStarDeals
question_inline id % 4 == 1
Question hook? Short observation about deal. Feature 1 | Feature 2 | Feature 3 CTA + link #QuadStarDeals
observation_arrows id % 4 == 2
Observation opener. → Feature or stat → Feature or stat → Feature or stat CTA + link #QuadStarDeals
prose_no_bullets id % 4 == 3
Short punchy hook sentence. Two sentences of prose describing the product and why the deal matters. CTA + link #QuadStarDeals
Self-Learning Feedback Loop
The Bot Gets Smarter With Every Posted Tweet

Engagement data flows back into the system prompt as explicit directives.

1
Tweet Posted
Approved deal is scheduled via Postiz. Postiz post ID saved alongside the tweet record.
tweet_learner.record_tweet()
2
Engagement Collected
Postiz analytics API polled for likes, retweets, replies. Stored in tweet_performance.json (last 200).
tweet_learner.collect_engagement()
3
Style Classified
Each tweet tagged with hook_type, cta_style, emoji count, feature count.
ab_testing.classify_style()
4
Winners Identified
Score = likes + retweets×2 + replies×3. Best hook type and CTA style computed. Falls back to A/B test data when <3 organic samples.
tweet_learner.get_style_guidance()
5
Directives Injected
Winners become explicit instructions in the LLM prompt: "USE hook_type=caps (n=12, avg engagement 47.3)".
notifier._build_system_prompt() injects style_guidance
6
Better Tweets Generated
Next LLM call biased toward proven winners. Loop continues — each cycle of posts tightens the signal.
