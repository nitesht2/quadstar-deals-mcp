QuadStar Deals

Automated Tech Deal Pipeline · DeepSeek V4 Flash · 4 Posts/Day

Pipeline Flow

  • • Scheduler fires at 4 peak PST times (±30min)
  • • Scraper fetches Amazon deals via Scrapling + Playwright
  • • 6 approval gates: discount, score, cooldown, confidence, price
  • • DeepSeek generates tweet copy with brand voice
  • • Format rotation: ~75% thread, ~25% single tweet
  • • Postiz schedules to X/Twitter

Anti-Detection

  • • Randomized posting times (jitter + shuffle)
  • • Random format (single vs thread)
  • • Brand voice: ~220 banned AI words
  • • Reply finder: disabled
  • • Max 4 posts/day
  • • Live price verification (no stale deals)

Infrastructure

  • • DeepSeek API: $0.0028/M cached tokens
  • • Postiz: Docker, self-hosted, auto-heal
  • • FastAPI: port 8001 via launchd
  • • Postiz healthcheck: every 5 min
  • • All data: local JSON files
  • • Total cost: ~$0.10-0.30/month
